# Shelly Gen1 Firmware Updates

Guides for updating Shelly Gen1 devices (for example the Shelly Plug S, SHPLG-S) when the device cannot update itself.

## Guides

- [Local firmware update manual](LOCAL_UPDATE.md): download the firmware, serve it from your own computer, and push it to the device. Includes the full firmware table with links for every Gen1 model.
- [Force update via browser](FORCED_UPDATE.md): point the device at the firmware on Shelly's servers with one URL in your browser. The device needs internet access.

## Quick start

1. Find your model in the firmware table of the local update manual.
2. If the device has internet access, use the browser guide.
3. If it does not, use the local update manual.

Always confirm your exact model before flashing. The Plug S (SHPLG-S) is Gen1. The Plus Plug S is Gen2 and needs different firmware.
